# Changelog

All notable changes to this course are recorded here. The format
follows Keep a Changelog, and the course versions follow semantic
versioning for the course as a whole.

## [1.0.0] - 2026-11-06

### Added

- Complete course: 32 lessons (00 to 31) across 9 modules, from the
  protocol on the wire to a published capstone server.
- LeadDesk MCP capstone: spec, build, hardening gate suite, and
  release routine across Lessons 28 to 31.
- Offline twins and logic layers in every lesson where behaviour is
  testable without the SDK, plus scripted smoke tests run in CI.
- Tools for contributors: a server manifest and config validator
  and a relative link checker, both wired into CI.
- Visual set in the TechAurah Academy style: course map, protocol
  exchange, primitives, transports, security layers, and capstone
  flow diagrams, generated by a committed script.
