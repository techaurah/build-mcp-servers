# Solution for Lesson 29: Build LeadDesk: tools, resources, and prompts, end to end

The stages resource is static reference data computed from the stage vocabulary the logic layer already owns (NEW, QUALIFIED, BOOKED, LOST, with the meanings from Lesson 10's solution). In the twin it joins RESOURCES with a read branch returning the stage list as JSON text; the smoke assertion lists resources and requires both URIs. The wrapper question: at twin level nothing in server_sdk.py changes, because this exercise completes the teaching model's surface, while the SDK server's resource registration is its own wrapper concern, covered when you register the same resource with the SDK's resource decorator in your fork. The sentence to write: behaviour lives in the vocabulary and the logic, and each protocol wrapper expresses it in its own idiom without inventing a second version.
