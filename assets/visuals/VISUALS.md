# Visual guide

Every core idea in this course has a diagram. They are drawn in one
style so the shapes stay familiar: navy boxes are the main actor or
step, light boxes are supporting steps, amber boxes are gates where
a human or a safety check decides. Each diagram also lives inside
the lesson it belongs to.

| Diagram | What it teaches | Used in |
|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 9 modules, one arc, one capstone | README |
| [protocol-exchange.svg](protocol-exchange.svg) | Initialize, discover, call: the wire exchange in order | Lesson 02 |
| [three-primitives.svg](three-primitives.svg) | Tools, resources, prompts, and who decides each | Lesson 03 |
| [transports.svg](transports.svg) | Stdio beside Streamable HTTP, with the deprecated shape named | Lessons 17, 18 |
| [security-layers.svg](security-layers.svg) | Annotations, scopes, approvals, and server side rules as layers | Lesson 20 |
| [capstone-flow.svg](capstone-flow.svg) | LeadDesk: capture, score, draft, book, with gates | Lessons 28 to 31 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py)
so the set stays consistent. Edit the script, rerun it, and commit
the SVGs it writes. Every use carries descriptive alt text, so
screen-reader learners and search engines get the same content as
sighted readers.
