# Solution for Lesson 11: Resource templates, subscriptions, and change notifications

Attack one: path traversal. A variable value of `../../.env` or an absolute style path escapes the intended directory and reads configuration and secrets, because the template expands text, not a checked location. Attack two: symlink escape. Even with traversal filtered, a symlink inside the directory pointing outside it lets a read follow the link beyond the boundary; canonicalising the final path and checking it stays under the allowed root is the standard defence, together with the roots model from Lesson 04. Safer design: address files by an opaque id from a server maintained index of deliberately published files (`leaddesk://files/{file_id}`), so the server only ever serves what it chose to expose, and the variable can name nothing else. Convenience kept, skeleton key removed.
