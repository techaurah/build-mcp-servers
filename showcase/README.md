# Capstone showcase

Finished LeadDesk servers from learners of Build MCP Servers.
This table is the course's completion artifact: no certificates,
just working servers anyone can open, run in demo mode, and inspect.

## How to get your capstone indexed

1. Finish the capstone (Lessons 28 to 31). Your project must be in
   a public repository of your own, with a README that says what
   the server does, how to run its demo, and honestly states its
   limits (teaching build, demo data, what it never does).
2. Fork this repository and add **one row** to the table below:
   your name or GitHub handle, a link to your capstone repository,
   and one line describing what your server does and its proudest
   honest limit.
3. Open a pull request titled `Showcase: <your handle>`. Small,
   single-purpose PRs like this merge directly under the course's
   [two-tier contribution rule](../CONTRIBUTING.md); you do not need
   to open an issue first.
4. A maintainer checks that the link works and the demo runs (or
   that the README honestly says what state it is in). Working
   beats polished.

One row per learner. If you rebuild your capstone later, update
your row with a second PR.
