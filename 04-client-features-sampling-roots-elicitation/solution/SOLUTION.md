# Solution for Lesson 04: Client features: sampling, roots, elicitation, logging, and progress

Course answer: elicit the appointment timezone, because bookings without one are wrong in a way users notice and servers cannot infer safely. Schema: one required string field `tz` presented as a short list of the business's common zones plus Other. On accept, book in that zone and state the zone in the result text so the model repeats it. On decline, return a result with isError false and text explaining nothing was booked and what to provide next time; a decline is information, not a failure. On cancel, stop immediately and book nothing. The anti pattern to avoid: eliciting the lead's email or any credential shaped fact; contact details arrive through tools and forms, not through a mid task popup asking for sensitive data.
