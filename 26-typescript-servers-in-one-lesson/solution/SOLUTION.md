# Solution for Lesson 26: TypeScript servers in one lesson, for Python learners

The registration mirrors the example: `server.registerTool("list_leads", { description: <the catalogue text, unchanged>, inputSchema: { stage: z.enum(["NEW", "QUALIFIED", "BOOKED", "LOST"]).optional() } }, handler)`. The careful place is exactly that enum: in Python the catalogue expressed it as a JSON Schema enum beside a string type, and a careless translation drops it to a bare `z.string()`, silently widening what callers may pass and what the logic must defend against. The handler filters the stub array by stage when present and returns `{ content: [{ type: "text", text: JSON.stringify({ leads, count }) }] }`, the same stable shape as the Python catalogue promises. Descriptions travel verbatim because they are the interface both models read.
