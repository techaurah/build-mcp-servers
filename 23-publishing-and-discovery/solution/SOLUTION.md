# Solution for Lesson 23: Publishing and discovery: Registry, directories, and a README that gets you found

Model bullets. Not a CRM: LeadDesk teaches and demonstrates the pipeline pattern; teams that outgrow it should graduate to a real CRM or to LeadPipe style storage they own. Sends nothing: no email, message, or notification leaves the server; drafts are returned for a human to send elsewhere. Demo data is fake: seeded leads are fictional, and demo mode must never be pointed at a production sheet. No multi user permissions in the teaching build: the auth tiers of Lesson 19 are designed and demonstrated at scope level, not a hosted identity system. Each bullet prevents a real misuse, which is what a limits section is for; a limits section that only says 'still in beta' protects nobody.
