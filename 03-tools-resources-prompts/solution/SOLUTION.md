# Solution for Lesson 03: Tools, resources, prompts: the three server primitives

Example answers for a clinic booking system. Tool: check available slots, because the model decides when availability matters mid conversation. Tool: book appointment (approval gated), because it is an action with side effects. Resource: today's schedule at `clinic://schedule/today`, because the host includes it as context and reading changes nothing. Resource: service catalogue at `clinic://services`, same reasoning. Prompt: `prepare-visit-summary`, because a receptionist invokes a known workflow before each appointment. Prompt: `handle-complaint`, because a person deliberately starts the careful path rather than the model wandering into it. The recurring test: name who decides, and the primitive follows.
