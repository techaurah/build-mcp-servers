# Solution for Lesson 17: Stdio in depth: process lifecycle, framing, and environment

Anchor to the server file: take the directory of `__file__` for the running module (or an explicit `LEADDESK_HOME` style env var when set), and build the cache path from that directory, never from the process cwd. Optionally honour an env override for tests and containers. The failures avoided: the host's arbitrary working directory (the cache silently landing in a documents folder, or a read only directory crashing startup) and the relative path drift between your terminal runs and host launched runs, which otherwise makes the same server behave like two different programs. If the directory is not writable, fail loudly at startup with the resolved path in the message, because a cache that cannot write should be a visible configuration error, not a mid session surprise.
