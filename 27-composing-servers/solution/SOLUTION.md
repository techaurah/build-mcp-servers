# Solution for Lesson 27: Composing servers: many servers, one client, and routing

Sentences: capture_lead: 'Store a new lead in the LeadDesk teaching pipeline (the spreadsheet style demo pipeline), deduplicating on email.' score_lead: 'Score a LeadDesk pipeline lead from its budget, timeline, and decision authority, using the LeadDesk rubric.' list_leads: 'List leads held in the LeadDesk pipeline, not the CRM, optionally filtered by LeadDesk stage.' The rule: the first sentence names the system of record the tool acts on, in the terms a user would use, because in a merged catalogue the model's routing question is never 'what does this do' in the abstract but 'which of these similar tools touches the thing the user means'. Where both servers could plausibly serve (a contact who is also a lead), the descriptions say which is canonical for what, and the honest systems note that dedup across the two is a workflow problem, not something either description may promise away.
