# Solution for Lesson 22: Packaging: project layout, entry points, and server.json

Declare it in the same package entry's environmentVariables list with isRequired true, isSecret false (an id is an identifier, not a credential; the credential that unlocks the sheet travels by the platform's own channel), a description naming what it identifies and where the owner finds it, and no default value, because a default sheet id would silently point strangers' servers at someone's data. Startup behaviour in live mode: fail before serving, with one stderr line naming the missing variable and the mode, nothing else. The message excludes other variables' values because startup errors get pasted into issues and screenshots; a diagnostic that leaks a second secret while reporting a missing first one is a vulnerability with good intentions.
