# Solution for Lesson 08: Structured content, return types, and tool annotations

For booking: the annotation is a promise the host uses to skip human confirmation. A booking writes to an external calendar; presenting it as a read is a false safety claim, and the first double booked customer pays for the faster demo. The correct speed fix is a dry run mode, not a false hint. For search: open world describes what the tool reaches, not how many providers you configured. Search results come from the open web, change without notice, and can contain injected instructions (Lesson 20); calling that closed world hides exactly the risk the hint exists to surface. Both refusals use the same principle: annotations describe the tool's real behaviour to software that cannot read your intentions.
