# Solution for Lesson 25: Versioning: protocol revisions, SDK lines, and keeping a course honest

Model note: 'LeadDesk was built and tested against the handshake era protocol, revisions 2025-06-18 through 2025-11-25, using the official Python SDK v1 line (mcp[cli]>=1.28,<2). Clients implementing those revisions connect without changes. The 2026-07-28 stateless revision is not yet a target for this teaching build; SDK v2 based hosts that retain handshake era compatibility work, and a v2 port is tracked as future work rather than promised. Last verified 2026-11-06 against the SDK repository and the specification.' The virtues to copy: it names revisions, names the pin, describes the other era honestly as untested rather than broken, and dates itself so staleness is visible at a glance.
